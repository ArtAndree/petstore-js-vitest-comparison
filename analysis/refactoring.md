# Рефакторинг тестового кода

Исходный код приложения пользователя не был приложен, поэтому сравнение выполнено на тестовой обвязке этого задания.

| Метрика | До рефакторинга | После рефакторинга |
|---|---|---|
| Читаемость | Повторяющиеся запросы и проверки в тестах | Общая функция `requestJson`, отдельные фабрики питомца/заказа/пользователя, понятные имена сценариев |
| Логические конструкции | Проверки HTTP и разбор JSON повторяются в тестах | Разбор ответа собран в одном месте; сценарии проверяют только результат своей операции |
| Имена переменных | Универсальные или короткие имена усложняют чтение | `updatedPet`, `readBack`, `order`, `username`, `response` отражают смысл |
| Скорость отклика | Не замерена: исходная версия не запускалась отдельно | Измеряется фактическим временем Jest/Vitest; сравнение требует запуска в одной сети |

В тестах оставлен таймаут сетевого запроса 20 секунд, чтобы зависший публичный API не блокировал проверку бесконечно. Фактическое время до и после нельзя заполнить честно без двух измерений на одной машине.
