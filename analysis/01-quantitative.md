# Анализ №1. Количественные показатели

В обоих наборах объявлено по 38 проверок. Данные ниже получены из успешного прогона GitHub Actions 24.11.2026 против публичного Swagger Petstore API.

| Показатель | Jest | Vitest |
|---|---:|---:|
| Количество тестов | 38 | 38 |
| Успешно пройдено | 38 | 38 |
| Завершилось с ошибкой | 0 | 0 |
| Время выполнения тестов | 1,534 с | 1,08 с |
| Полная длительность шага раннера | 1,534 с | 1,34 с |

У Jest в логе указана полная длительность раннера: 1,534 с. Vitest показывает длительность тестов 1,08 с, а общую длительность процесса — 1,34 с. Это значения одного запуска в GitHub Actions, а не устойчивый бенчмарк: на них влияют сеть, время ответа публичного API и нагрузка CI.

Команды повторного запуска приведены в корневом `README.md`. Для сравнимых цифр запусти оба набора в одной среде несколько раз и сравни медиану.

## Почему цифры могут меняться

Тесты выполняются против публичного демонстрационного сервера. На результаты влияют доступность сети, задержки, лимиты и изменения состояния сервера. Поэтому результаты отражают конкретный запуск, а не гарантированную скорость фреймворка.
